# Sample files

Copies of the import test fixtures, here so the "Review in 60 seconds" walkthrough in
`README.md` and `SUBMISSION.md` points at files that actually exist.

| File | Try it for |
|---|---|
| `sample.md` | headings, bold/italic/underline, nested bullets, an ordered list — plus a fenced code block and a link, which are **deliberately dropped** on import because they are outside the supported node set |
| `sample.txt` | paragraph splitting and line breaks |
| `sample.docx` | a real Word file: headings, bold, italic, underline, bullets |

Supported files: `.md`, `.txt`, `.docx` — maximum 2 MB per file.
